# NASA APOD XHR and Fetch Demo

Just using the quick and easy NASA APOD API to show how XHR and Fetch can be used.

## 🚀 Available Scripts

| Command                | Description                                                                 |
|------------------------|-----------------------------------------------------------------------------|
| `npm start`            | Starts the local web server (http-server)                                   |
| `npm test`             | Runs **Jest** unit/module tests                                             |
| `npm run test:e2e`     | Runs **Playwright** end-to-end (UI) tests                                   |
| `npm run test:all`     | Runs **both** Jest and Playwright tests in sequence                         |
| `npm run test:vitest:run`| Runs tests once and then exits                                             |

### 1. Start the Development Server
```bash
npm start
```
Open your browser and go to: **http://localhost:8080**

### 2. Run Tests

- **Unit tests only** (Jest):
  ```bash
  npm test
  ```

- **Unit tests only** (Vitest):
  ```bash
  npm test:vitest:run
  ```

- **End-to-End tests only** (Playwright):
  ```bash
  npm run test:e2e
  ```

- **Run all tests** (recommended):
  ```bash
  npm run test:all
  ```

## Test Reports

- **Playwright HTML Report**: `playwright-report/index.html` (open this in browser)
- **Jest JSON results**: `test-results/jest-results.json`
- **Playwright JSON results**: `test-results/playwright-results.json`
